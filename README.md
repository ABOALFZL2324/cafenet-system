# 🖥️ سامانه جامع مدیریت کافی‌نت و مرکز خدمات رایانه‌ای (CafeNet Manager)

یک نرم‌افزار دسکتاپ مدرن، سریع، آفلاین و تخصصی برای مدیریت کامل عملیات، شیفت‌ها، فاکتورها، هزینه‌ها، پرسنل و تسویه‌حساب ماهانه در کافی‌نت‌ها و مراکز خدمات اینترنتی و چاپ.

---

## 🌟 ویژگی‌ها و امکانات برجسته

### ۱. 🚀 راه‌اندازی اولیه آسان، پشتیبانی از شبکه محلی (LAN) و ورود اطلاعات با اکسل
- **اتصال چند سیستم به یک دیتابیس مشترک (LAN Multi-PC):** قابلیت استفاده همزمان چندین سیستم در مغازه (تعیین نقش سیستم اصلی Server یا سیستم متصل Client بدون نیاز به سرور اینترنتی).
- **بستن خودکار شیفت با خاموش شدن سیستم:** بستن امن شیفت و ثبت لاگ خروج در صورت خاموش شدن ناگهانی یا شات‌دان ویندوز.
- **ویزارد راه‌اندازی اولیه (Onboarding Wizard):** فرم گام‌به‌گام برای تعریف مشخصات کافی‌نت، نقش کامپیوتر در شبکه، مدیر سیستم و همکاران.
- **ایمپورت سریع نرخ‌نامه با اکسل:** امکان دانلود فایل اکسل خام، تکمیل عناوین خدمات و تعرفه‌ها در اکسل و بارگذاری یکپارچه در سیستم با یک کلیک.

### ۲. 📖 حساب دفتری و فروش نسیه (Customer Debts & Credit)
- **ثبت فروش نسیه:** امکان ثبت پرداخت به صورت «نسیه / حساب دفتری» با ثبت نام و تلفن مشتری.
- **دفتر حساب و تسویه مطالبات:** صفحه اختصاصی با نمایش کل طلب‌ها، مشتریان بدهکار و تسویه آنی به صورت نقدی یا با کارت‌خوان.

### ۳. 🌐 داشبورد لینک‌های سریع و پرکاربرد کافی‌نت
- **دسترسی سریع به سامانه‌های دولتی:** لینک‌های مستقیم و تفکیک‌شده سامانه‌های انتظامی (سخا، راهور)، قضایی (عدل ایران، ثبت من)، آموزشی (مای‌مدیو، سنجش)، مالیاتی (مای‌تکس، درگاه ملی مجوزها) و بیمه.

### ۴. 👥 مدیریت اپراتورها، حضور همزمان و نمایش آنی سهم متصدی
- **ویجت نمایش زنده سهم متصدی:** نمایش لحظه‌ای پورسانت و کارمزد کسب‌شده توسط متصدی حاضر در طول شیفت کاری فعال.
- **حضور همزمان چند کارگر:** قابلیت ثبت حضور همزمان چندین اپراتور در یک شیفت کاری و مدیریت در حین شیفت.
- **محاسبه دقیق ساعات کارکرد:** ثبت خودکار طول مدت حضور با قابلیت ویرایش دقیق ساعات کارکرد هر یک از پرسنل در لحظه تحویل شیفت.
- **حفظ حریم خصوصی و امنیت سوابق:** حذف منطقی (Soft Delete) اپراتورها جهت نگهداری همیشگی سوابق مالی.

### ۳. 💰 سه مدل پیشرفته و منعطف محاسبه حقوق و تسویه سود
1. **روش اول (شراکتی):** تقسیم سود بر مبنای درصد توافق‌شده از سود خالص کل کافی‌نت (درآمد منهای هزینه‌های عمومی).
2. **روش دوم (پورسانت عملکردی فردی):** محاسبه سود بر پایه فاکتورهای ثبت‌شده توسط هر اپراتور با تسهیم عادلانه هزینه‌ها.
3. **روش سوم (محاسبه ساعتی بر مبنای حضور و سهم کارفرما):**
   - تعیین درصد مشخص سهم کارفرما از سود خالص.
   - محاسبه ارزش ریالی هر ساعت کارکرد بر اساس باقی‌مانده سود و مجموع ساعات حضور پرسنل.
   - پرداخت حقوق هر کارگر دقیقاً متناسب با مجموع ساعات کارکرد ثبت‌شده او در ماه.

### ۴. 🧾 صندوق و صدور فاکتور پرسرعت
- **کلید میانبر صدور فاکتور:** دسترسی فوری با کلید میانبر `Ctrl + N`.
- **ثبت خدمات آزاد و متفرقه:** علاوه بر خدمات مصوب، امکان ثبت خدمات ویژه و قیمت دلخواه برای کارهای اختصاصی.
- **محاسبه‌گر پرینت و تکثیر:** ابزار سریع برای محاسبه پرینت تک‌رو، دورو، رنگی، صحافی و تخفیف.
- **پشتیبانی کامل از کیبورد فیزیکی:** امکان ورود مستقیم پین‌کد و ارقام با صفحه کلید بدون نیاز به کیبورد مجازی.

### ۵. 🖨️ چاپ حرفه‌ای و استاندارد
- **چاپ تمیز فاکتور مشتری:** چاپ صرفاً فاکتور با طراحی استاندارد (بدون هدر و فوتر ناخواسته مرورگر و صفحه).
- **لوگوی اختصاصی کافی‌نت:** امکان آپلود لوگو در تنظیمات و چاپ در سربرگ فاکتور.
- **برگه رسمی تسویه ماهانه A4:** سند استاندارد با تفکیک هزینه‌ها، سهم پرسنل، ارزش ساعت کاری و محل امضا و مهر مدیریت و پرسنل.
- **خروجی اکسل کامل (.xlsx):** دریافت فایل اکسل استاندارد از فاکتورها، هزینه‌ها و گزارش تسویه سود ماهانه.

### ۶. 🎨 رابط کاربری و تجربه کاربری مدرن (UI/UX)
- **پشتیبانی از تم دارک و لایت (Dark/Light Mode):** سازگاری کامل تضاد رنگی، بدون سفید شدن ناگهانی صفحه یا تداخل دیداری.
- **داشبورد زنده:** نمایش تایمر زنده شیفت، پرسنل حاضر در باجه، نسبت درآمدهای کارتخوان به نقد و کارهای در دست اقدام (Pending Orders).

### ۷. 🔒 معماری آفلاین و پایداری کامل داده‌ها
- **بدون نیاز به اینترنت:** کارکرد کاملاً محلی در شبکه و کامپیوتر مغازه.
- **پایداری صددرصد روی دیسک:** ذخیره‌سازی در فایل محلی `cafenet_db.json` در مسیر امن سیستم ویندوز (`%APPDATA%`). بستن برنامه، ریست سیستم یا قطعی برق اطلاعات را از بین نمی‌برد.
- **پشتیبان‌گیری (Backup):** امکان پشتیبان‌گیری و بازیابی داده‌ها با بررسی سلامت فایل.

## 🛠️ راهنمای اجرا و نصب

### روش اول: استفاده از فایل نصبی خودکار ویندوز (پیشنهادی)
یک فایل نصاب آماده با آیکون اختصاصی و شورت‌کات دسکتاپ و استارت منو تولید شده است:
1. فایل نصاب موجود در پوشه `installer` را دریافت و اجرا کنید:
   ```
   installer/CafeNet-Manager-Setup-1.0.0.exe
   ```
2. مسیر نصب را مشخص کرده و روی **Next** کلیک کنید.
3. شورت‌کات برنامه با نام **«مدیریت کافی‌نت»** به صورت خودکار روی **دسکتاپ** و **منوی استارت** ایجاد می‌شود.

---

### روش دوم: اجرای سورس کد و توسعه (ویژه توسعه‌دهندگان)

#### پیش‌نیازها:
- Node.js (نسخه 18 یا بالاتر)
- npm

#### مراحل راه‌اندازی:
```bash
# ۱. دریافت مخزن
git clone https://github.com/<username>/cafenet-system.git
cd cafenet-system

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای محیط توسعه
npm run dev

# ۴. اجرای برنامه در قالب دسکتاپ الکترون
npm run start

# ۵. ساخت فایل نصبی ویندوز (.exe)
npm run dist:win
```

## 📂 ساختار فایل‌های پروژه
```text
cafenet-system/
├── electron/              # فرآیند اصلی الکترون و وب‌سرور داخلی پایدار
│   └── main.cjs
├── src/
│   ├── components/        # کامپوننت‌های رابط کاربری
│   │   ├── dashboard/     # داشبورد اصلی، وضعیت شیفت، حاضرین، فروش سریع
│   │   ├── invoices/      # مدیریت و چاپ فاکتورها
│   │   ├── settlement/    # حسابداری، تسویه ماهانه و برگه چاپی رسمی A4
│   │   ├── onboarding/    # ویزارد راه‌اندازی اولیه و ورود با اکسل
│   │   ├── services/      # نرخ‌نامه و دسته‌بندی خدمات
│   │   ├── operators/     # مدیریت اپراتورها و همکاران
│   │   └── settings/      # تنظیمات عمومی، لوگو و پشتیبان‌گیری
│   ├── context/           # کانتکست‌های وضعیت داده و احراز هویت
│   │   ├── AuthContext.tsx
│   │   └── DataContext.tsx
│   ├── types/             # تعاریف تایپ‌های TypeScript سیستم
│   └── utils/             # توابع تقویم جلالی، اکسل، ارز و امنیت
├── build/                 # آیکون‌های استاندارد برنامه (.ico و .png)
├── cafenet_db.json        # قالب خام پایگاه‌داده محلی
└── package.json
```
