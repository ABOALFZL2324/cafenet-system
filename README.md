# 💻 سیستم جامع مدیریت کافی‌نت (CafeNet Manager)

یک نرم‌افزار دسکتاپ مدرن، سبک، کاملاً آفلاین و متناسب با سبک طراحی **ویندوز ۱۱ (Fluent Design)**، ویژه مدیریت امور روزمره، مالی، پرسنلی و عملیاتی کافی‌نت‌ها و مراکز خدمات اینترنتی.

---

## ✨ ویژگی‌های برجسته نرم‌افزار

- 🔒 **۱۰۰٪ آفلاین و مستقل از اینترنت (Zero Internet Dependency):** بدون نیاز به اتصال شبکه یا وابستگی به سرورهای خارجی؛ تمامی فونت‌ها، آیکون‌ها، موتور تقویم شمسی و پایگاه‌داده به صورت محلی در سیستم اجرا می‌شوند.
- 🎯 **اصل قطعیت داده‌ها (Real Data Only):** صفر درصد حدس یا ارقام ساختگی؛ کلیه آمارها، نمودارها و سودها مستقیماً از تراکنش‌ها و اقلام واقعی ثبت‌شده محاسبه می‌گردند.
- ⚡ **ثبت سریع دریافتی و فاکتور چندخدمتی:** امکان ثبت چند خدمت در یک فاکتور (مانند پرینت + ثبت‌نام اینترنتی + لوازم) همراه با امکان ثبت فوق‌سریع تک‌خدمت با یک کلیک.
- 🖩 **محاسبه‌گر هوشمند پرینت و کپی:** محاسبه خودکار و آنی قیمت برگه‌ها بر اساس تعداد صفحات، رنگی/سیاه‌سفید، تک‌رو/دورو و انتقال مستقیم به فاکتور.
- 🧾 **صدور و چاپ فاکتور در دو قطع استاندارد:**
  - رول حرارتی ۸۰ میلی‌متری (فیش‌پرینتر)
  - فاکتور رسمی قطع A5 (مناسب شرکت‌ها و ادارات)
  - امکان ذخیره فوری نسخه PDF برای ارسال در پیام‌رسان‌ها
- 📋 **میز کار و دفتر سفارشات معلق (Handover):** انتقال وظایف بین شیفت‌ها همراه با مشخصات مشتری، بیعانه دریافتی و محل مدارک امانی تا هیچ کاری بین تعویض شیفت‌ها فراموش نشود.
- ⏱️ **مدیریت شیفت و ساعات کارکرد:** ثبت دقیق ساعت ورود و خروج متصدیان با انتخاب کاربر و پین‌کد سریع، همراه با یادداشت پایان شیفت.
- 💰 **موتور تسویه سود ماهانه بر اساس تقویم شمسی:**
  - پشتیبانی از هر دو مدل مالی: **مدل شراکتی (درصد از سود کل)** و **مدل پورسانت عملکردی فردی (با تسهیم هزینه)**.
  - کسر هزینه‌های تاییدشده مغازه در طول ماه از سود.
  - صدور برگه رسمی تسویه‌حساب در قطع A4 با کادر امضای دوطرفه متصدی و صاحب کافی‌نت.
  - خروجی جامع و تمیز فایل اکسل (`.xlsx`) از تراکنش‌ها، هزینه‌ها و سهم پرسنل.
- 📊 **هوش تجاری و آمار تحلیلی:** شناسایی پردرآمدترین خدمات، پرتقاضاترین خدمات، خدمات راکد و بدون فروش، و نسبت درصدی دریافتی کارتخوان در برابر نقدی.
- 🛡️ **حالت حریم خصوصی سریع (Privacy Lock):** امکان قفل و مات کردن فوری صفحه با کلید میانبر (`Alt + L`) در حضور مشتری جهت مخفی‌سازی اطلاعات مالی.
- 💾 **پشتیبان‌گیری و بازیابی پایگاه‌داده (Backup & Restore):** امکان خروجی فایل پشتیبان با یک کلیک و بازیابی آسان در صورت تغییر سیستم.

## 🛠️ ساختار فنی و ابزارها (Tech Stack)

- **فریم‌ورک دسکتاپ:** Electron v35 (با خروجی نصبی NSIS Installer برای ویندوز)
- **فرانت‌اند:** React 19 + TypeScript + Vite 6
- **طراحی و رابط کاربری:** Tailwind CSS + Lucide Icons + تم فلوئنت ویندوز ۱۱ (پشتیبانی از حالت تیره و روشن)
- **تقویم و تاریخ:** موتور اختصاصی جلالی شمسی (Jalaali)
- **پایگاه‌داده:** لایه ذخیره‌سازی محلی سریع و پایدار
- **گزارش‌گیری:** کتابخانه XLSX برای تولید اسناد اکسل

## 🚀 راهنمای راه‌اندازی و توسعه (Development)

### پیش‌نیازها:
- Node.js (نسخه 18 یا بالاتر)

```bash
# کلون کردن مخزن
git clone https://github.com/your-username/cafenet-system.git
cd cafenet-system

# نصب وابستگی‌ها
npm install

# اجرای نسخه تحت وب (توسعه سریع)
npm run dev

# اجرای نسخه نرم‌افزار دسکتاپ ویندوز
npm run start
```

## 📦 تولید فایل نصبی ویندوز (`Setup.exe`)

برای ساخت بسته نصبی رسمی ویندوز که مانند نرم‌افزارهای تجاری در `Program Files` نصب شده و میانبر دسکتاپ و منوی استارت ایجاد می‌کند:

```bash
npm run dist:win
```

فایل نصبی نهایی در پوشه `release/` با نام **`CafeNet Manager Setup 1.0.0.exe`** ساخته خواهد شد.
